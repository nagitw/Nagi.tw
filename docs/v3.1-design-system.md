## 視覺規格

- Dark-first：未儲存主題時使用深色；Light Mode 可切換並記憶。儲存失敗時仍可使用。
- 色彩建議：背景 `#111315`、表面 `#191c20`、正文 `#eceef1`、次要文字 `#a9b1bc`、細線 `#30363e`、Nagi Blue `#70b7ff`。淺色對應背景 `#fafafa`、正文 `#18212c`、藍色 `#075fae`；最終以對比與實際畫面調整。
- 使用系統字體，繁中優先適用的 sans-serif stack；程式碼使用 monospace，不新增遠端字型請求。
- 正文 17–18px、行高約 1.85；文章內容最大 760px，手機水平留白 20px。首頁與索引最大約 1080px。
- 標題依裝置縮放，清楚區分 h1/h2/h3；小型英文眉標只輔助，不取代中文標題。
- 以留白、細分隔線與文字層級組織資訊，減少卡片、圓角及裝飾。
- 所有互動有可見鍵盤焦點；觸控目標至少 44px；尊重 reduced-motion。
- Penguin、NagiPenguin 與原有角色素材不改造、不刪除，保留既有聊天互動與模式標示。

## 資訊架構

首頁順序固定為：Navbar → Nagi Hero → Latest Writing → Featured Research → Selected Projects → About Preview → Footer。

導覽優先呈現 Journal、Research、Projects、Experience、About；技術報告、漏洞揭露與聯絡仍由次要導覽或 Footer 可達。手機採可展開導覽，無 JavaScript 仍可到達連結。首頁移除目前工作方向與未來計畫區塊，只以核准公開文章、研究與工程紀錄組成精選；沒有合格資料時明示空狀態，不填造。

Hero 使用 Nagi 既有自介與原企鵝。About Preview 重用現有公開自介。繁中優先表現在內容與排版，不交換 `/` 和 `/zh/` 的既有語系語意、不建立自動轉址；英文切換與翻譯缺漏提示保留。

## Journal 與文章

- 四分類維持 Cybersecurity、Medical、Perspectives、Reflections；單欄 Editorial List 顯示標題、摘要、日期、分類與「估算閱讀時間」。
- 閱讀時間以經公開過濾的正文估算，中文字元與英文詞數分別估計，最少 1 分鐘；不聲稱精準閱讀時間。
- 由同一次 Markdown 解析產生穩定且去重的 heading IDs 與 TOC；不改文章路徑。
- 程式碼在建置時高亮；未知語言安全退回純文字。Copy Code 支援鍵盤、成功與失敗提示，保留原始程式碼文字。
- Heading Anchor 可直接複製或開啟；不讓錨點符號干擾標題朗讀。
- 正文圖片限核准的本地或安全 HTTPS 來源，保留 alt、比例與響應式寬度；不因新增圖片支援而允許原始 HTML 執行。
- 參考資料保留原文來源；如另生成來源列表，僅整理既有有效引用，不生成虛構文獻。
- 上下篇只使用已發布 Journal，依日期排序及穩定的同日排序，語系使用既有 fallback 規則。其他種類紀錄不混入 Journal 上下篇。
