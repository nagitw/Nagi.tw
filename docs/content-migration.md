# Content migration audit

Generated by `node scripts/migrate-content.mjs`. Only explicit migration reads legacy siblings. Site builds use the committed local JSON and image. No private archive or internal medical project source is read.

Inventoried 139 Markdown files; imported 51 public editions (18 journal, 9 project, 10 lab, 2 research, 2 report, 8 experience, 2 reference). Chinese and English are independent editions; unavailable translations are not invented.

## Decisions and limits

- Legacy config exclusions and published:false quarantine the full translation group, including the mismatched speaking/teaching pages. No teaching record is promoted from an unpublished source.
- Current Notes articles supersede duplicate Hexo posts; original dated URLs are retained in aliases. Japanese editions remain on Notes and are inventoried, not imported.
- Public medical reflections and public project summaries are retained. MedTrust public presentation HTML becomes inert Markdown, with explicit prototype limitations intact. No implementation repository or private archive is accessed.
- Empty records and navigation templates do not become completed articles. Lab statuses distinguish archival notes, completed learning notes, and learning plans. Source claims are historical author statements, not independently verified outcomes.
- CYBERSEC cover was visually checked: conference signage, no personal identity. It is copied locally. Identity/brand covers are omitted; no screenshot with personal identifiers is copied. No inline Markdown images were found in the imported source bodies.
- Known identity labels and personal contact details are sanitized; named teammate attribution is generalized. No prohibited certification claim is imported.
- The report records paths, not unpublished body text. A missing target means deliberate exclusion/manual review. Original navigation/profile pages are replaced by the new site's curated pages.
- Local Markdown links map to imported canonical pages when available; other links preserve the original public origin. Publishing aliases/redirects is handled by the site route layer.

## V3 integration decisions (2026-11-06)

- 51 editions now render through 30 paired content paths: 60 content pages including nine explicit missing-translation notices. Canonical English paths remain `/`; Traditional Chinese remains `/zh/` to retain established URLs. The earlier phase2 proposal for `/en/` was not adopted.
- 17 non-conflicting local legacy aliases become static redirects. Existing canonical pages take precedence over conflicting aliases. Notes URLs and Japanese editions remain external.
- Homepage journal previews are date-descending and limited to three. Live remote RSS no longer feeds public pages; reviewed local editions supply the journal, RSS and search index. Penguin AI uses only four curated public topic summaries, not full article bodies.
- Nagi CLI, Nagi Medical Agent, RuralMed-Sat, AEUST Life, Nagi Sudoku and BugTraceAI: no sufficient publishable documentation found in the inventoried source Markdown or portfolio/research/home data. Each has a bilingual pending-information page; no architecture, result or GitHub repository URL is invented.
- Nagi Notes: existing local Notes articles and the known public Notes URL are evidence; articles migrated, technical architecture/repository details remain pending.
- MedTrust, Autonomous Robot, Medical Cybersecurity and Home Lab retain their public source pages, prototype/learning scope and limits. Drone/communication interests are represented only to the extent present in public research/lab notes; no completed research result invented.
- Speaking/teaching translation groups marked unpublished remain excluded. Public workshop/CTF/experience records remain accessible from Experience.
- No authorized real security disclosure was found. The disclosure dataset is empty, with a working publication gate and index/detail/year generation for future authorized records. Synthetic tests are never imported by the website.
- CYBERSEC image was visually rechecked during this integration: event signage only. Other identity/brand covers are not exposed.
- Draft series sources are retained locally in the repository but generate no routes; old public output is cleaned before production build. No source history is rewritten.
