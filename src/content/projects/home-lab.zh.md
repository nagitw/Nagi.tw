# Home Lab

自架服務與個人基礎設施。

領域: 基礎設施

狀態: 目前

範圍: 個人基礎設施

## 系統定位

Home Lab 是我用來跑服務、整理網路邊界、測試遠端存取與留下復原紀錄的基礎設施環境。

它和 MedTrust 是不同系統。兩者可能共用一些工具，但 Medical IoT 信任研究與個人基礎設施維護不是同一件事。

## 目前元件

- Ubuntu Server

- Docker

- Tailscale

- OpenWrt

- MQTT

- Node-RED

- Networking

- Service hosting

## 目前方向

- 記錄網路邊界與服務暴露範圍。

- 保留故障與服務重建的復原紀錄。

- 公開內容會避開敏感操作細節。
